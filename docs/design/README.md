## Rules

- Branch: `docs/HAP-<ticket>-<yourname>` → open a pull request → Pasan reviews and merges.
- Commit messages start with your ticket key, e.g. `HAP-25: add landing page wireframes`.
- draw.io: commit the `.drawio` file. Figma: commit a PNG/PDF export and a `figma-link.md`.
- Never commit passwords, API keys, or interview/participant data.
- Keep files under 10 MB. Commit small and often.
